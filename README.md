# zt-svitlo-bot

Бот графіків відключень Житомира: підписка на свою чергу (1.1–6.2), повідомлення лише коли графік черги з'являється або змінюється, зведення в канал.

## Запуск на демо-даних

```bash
pip install -r requirements.txt
cp .env.example .env        # вписати BOT_TOKEN від @BotFather
python bot.py
```

Поки бот працює, змініть будь-який інтервал у `data/demo.json` — за кілька хвилин прийде сповіщення підписникам цієї черги і пост у канал (якщо заданий `CHANNEL_ID`). Перший запуск запам'ятовує стан мовчки, щоб не розіслати все одразу.

Як користувач знаходить свою чергу: `/start` пропонує «Знайти чергу за адресою» або «Я знаю свою чергу». Будь-який текст у приваті бот сприймає як адресу: «Київська 24» одразу дає чергу і кнопку підписки, «Київська» — вибір вулиці й питання про номер будинку. Пошук іде через форму на сайті обленерго (`address.py`, лише місто Житомир; вулиці кешуються на добу, будинки — на 6 годин).

Команди: `/start` пошук черги, `/my` мій графік на сьогодні й завтра (зі смужкою по годинах), `/stop` відписка, `/stats` кількість підписників. Меню команд бот задає сам при запуску.

## Що отримують люди

**Канал:**
- картинка графіка (`card.py`, 1080×1350, шрифт Manrope з `fonts/`, OFL) і підпис з годинами по всіх 12 чергах (`posts.channel_caption`);
- оновлення графіка — відповіддю на перший пост дня, з плашкою «ОНОВЛЕНО» і ✏️ біля змінених черг; скасування — «✅ Відключення скасовано»;
- за 15 хв до кожного перемикання — пост «О 16:30 · Вимикаємо / Вмикаємо / Ще без світла», відповіддю на картинку дня;
- під кожним постом кнопка «🔔 Сповіщення для моєї черги» (веде в бота).

**Бот (особисто, лише по своїх чергах):**
- зміни графіка з тим, що було, і смужкою 🟩🟥 по годинах;
- «⏰ Через 30 хв вимкнуть світло» і «💡 Світло має повернутись» з наступним відключенням; вимикаються кнопкою під повідомленням або в `/my`.

Перемикання рахує `posts.switch_events` по сьогодні+завтра (злиття через північ), розсилку робить джоб `tick` щохвилини; таблиця `sent` не дає дублів після рестарту.

**Меню:** постійні кнопки внизу чату — «🔎 Знайти чергу за адресою», «📅 Мій графік», «🔢 Мої черги», «⏰ Нагадування», «❓ Допомога». Адміни каналу бачать ще «📢 Новий пост» і «🖼 Графік у канал» (меню з'являється після `/start`).

**Ручні пости (адміни каналу):** «📢 Новий пост» або `/post` → надіслати текст/фото/відео з будь-яким форматуванням → бот показує прев'ю точно як у каналі → «✅ Опублікувати», перемикач кнопки «Сповіщення для моєї черги» під постом, «✏️ Інший варіант», «❌ Скасувати». Альбоми (кілька фото одним повідомленням) поки не підтримуються — піде лише перше фото.

**Для адмінів каналу:** `/preview` — надсилає в особисті картку, оновлення, пост перемикання і нагадування (на демо-даних, якщо реальних відключень немає), а для реального графіка — кнопку «✅ Опублікувати» в канал; `/testpost` — тестова картка в канал.

## Джерело ztoe (`SOURCE=ztoe`)

Графік береться з таблиці «Графіки погодинних відключень» на https://www.ztoe.com.ua/unhooking-search.php: звичайний HTML у windows-1251, рядок на підчергу, 48 півгодинних клітинок на кожну дату, червоний фон — відключення. Парсер — `parse_ztoe()` у `source.py`. Якщо структура сайту зміниться, парсер кидає помилку з поясненням, бот пише її в лог і нічого не розсилає.

Новий день без відключень з'являється щодня — про нього бот мовчить. При зміні `SOURCE` старі знімки стираються, щоб не розіслати хибні «зміни».

## Перевірка каналу

`/preview` показує всі формати в особистих, `/testpost` публікує тестову картку в канал (обидві — лише для адмінів каналу).

## Перед запуском на реальних даних

- Перевірити умови використання сайту обленерго.
- Не опитувати частіше, ніж раз на 5–10 хвилин.
